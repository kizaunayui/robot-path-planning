# 机器人在线实时路径规划软件

基于 React 19 + Vite 8 + Tailwind CSS 4 的医院机器人路径规划与仿真系统。

## GitHub Pages

https://kizaunayui.github.io/robot-path-planning/

## 核心功能

| 模块 | 说明 |
|------|------|
| 🗺️ 地图总览 | Canvas网格地图、障碍物/动态障碍、科室节点、机器人位置、路径高亮 |
| 📐 路径规划 | 选择起终点→三策略A*路径（时间/平稳/节能）→指标对比→切换高亮 |
| 📦 任务派发 | 选择路径→派发→机器人状态变化→activeTasks更新 |
| 🗺️ 地图编辑器 | 绘制墙壁/动态障碍/擦除/随机地图/调整尺寸/保存加载localStorage |
| 🚦 交通规则 | 6种规则管理：手术区优先/污染区避让/平稳优先/低电量节能/禁行区/限速区 |
| 🎮 仿真沙盒 | 随机起终点演练→成功率/平均长度/转弯/耗时/能耗统计 |
| ⚙️ 路径配置 | 策略/灵敏度/缓冲参数配置 |
| 📍 诊断 | 系统诊断+机器人状态 |
| 🔋 充电管理 | 充电站与电量管理 |
| 🌡️ 区域代价 | 区域代价地图配置 |
| ⚠️ 碰撞预警 | 碰撞检测与预警 |
| 🔺 导航网格 | 三角网格导航 |
| 🤖 多机器人 | 多机器人协同管理 |
| 📋 任务分配 | 任务队列与分配策略 |
| ⚙️ HIS策略 | HIS系统策略配置 |

## 算法核心（从planner.py移植）

- **A*搜索**：网格A*支持三种策略（time/smooth/energy）
- **移动代价**：转弯惩罚 + 规则权重影响
- **路径报告**：length/turns/minutes/energy/score
- **地图验证**：freeCells/walls/dynamic/connected统计
- **沙盒演练**：随机起终点多轮测试，统计成功率
- **地图编辑**：绘制障碍/动态障碍/随机地图/调整尺寸

## 演示流程

1. 打开地图，查看默认网格和科室
2. 在地图编辑器添加墙壁/动态障碍
3. 选择起点终点，计算三种策略路径
4. 对比路径指标（距离/转弯/耗时/能耗）
5. 启用/停用交通规则，观察路径变化
6. 派发任务，查看机器人状态变化
7. 运行沙盒演练，查看统计结果
8. 查看日志记录

## 本地运行

```bash
npm install
npm run dev
npm run build
```

## 当前限制

- 纯前端mock仿真，不接真实后端
- 地图为网格化，非真实CAD地图
- 机器人移动为路径展示，非实时动画
- 沙盒演练为单轮统计，非连续仿真

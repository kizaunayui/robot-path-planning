# 医院机器人路径规划系统

基于 React + Vite + Tailwind CSS 的医院多机器人路径规划与调度管理系统。

## 功能模块

| 模块 | 说明 |
|------|------|
| 🗺️ 地图总览 | 医院3层楼地图可视化，显示所有节点、区域、机器人位置 |
| 📐 路径规划 | A*算法路径规划，支持起点终点选择、路径动画展示 |
| 📦 任务派发 | 创建运输任务，计算多条推荐路径（A/B/C），选择机器人派发 |
| 🗺️ 地图编辑器 | Canvas地图编辑工具，支持添加节点/墙体/门/障碍物，路径验证 |
| 🚦 交通规则 | 6种交通规则管理：区域限速、单行通道、路口让行、禁行区域、紧急优先、时间段管控 |
| 🎮 仿真沙盒 | 机器人沿路径移动的动画仿真，碰撞检测、速度统计、日志记录 |
| ⚠️ 碰撞预警 | 实时碰撞检测与预警 |
| 🔺 导航网格 | 三角网格导航 |
| 🤖 多机器人 | 多机器人协同管理 |
| 📋 任务分配 | 任务队列与分配策略 |
| 🌡️ 区域代价 | 区域代价地图配置 |
| ⚙️ HIS策略 | HIS系统策略配置 |
| 🔋 充电管理 | 充电桩与电量管理 |
| 📍 诊断 | 机器人诊断日志 |
| ⚙️ 路径配置 | 路径参数配置 |

## 技术栈

- **React 19** + **React Router 7**
- **Vite 8** 构建工具
- **Tailwind CSS 4** 样式
- **Canvas API** 地图渲染
- **A* 算法** 路径规划

## 地图数据模型

- 3层楼医院地图（1200×800 像素/层）
- 每层15+个节点（药房、手术室、病房、电梯厅、充电站等）
- 跨楼层电梯连接
- 区域块（门诊区、急诊区、手术区等）带限速属性
- 6个运输机器人，带电量、速度、状态属性

## 快速开始

```bash
npm install
npm run dev     # 开发模式
npm run build   # 生产构建
```

## 项目结构

```
src/
├── data/
│   ├── mapData.js      # 医院地图数据模型（节点、边、区域、机器人）
│   └── mockData.js     # 其他模块mock数据
├── utils/
│   └── pathfinding.js  # A*路径规划算法
├── components/
│   ├── HospitalMap.jsx  # Canvas地图组件
│   ├── Layout.jsx       # 布局组件
│   ├── Sidebar.jsx      # 侧边栏导航
│   └── StatusCard.jsx   # 状态卡片
├── pages/               # 15个功能页面
├── store/
│   └── AppStore.jsx     # 全局状态管理
├── App.jsx              # 路由配置
└── main.jsx             # 入口
```
